# External Research, Alternatives, and License / Provenance Notes

This page records approaches reviewed to avoid assuming Version 01's architecture is the only option. The challenger implementation was written locally for this repository. It does not vendor, copy, or re-label third-party vectorizer source code. References below informed architectural choices or future-work assessment only.

## Alternatives researched but not implemented

- **Topology-preserving shared-boundary region graph:** label raster pixels/superpixels, represent each shared border once in a planar graph, maintain holes/containment explicitly, then simplify a common boundary under a Hausdorff or signed-distance error budget before Bézier fitting. This is the better direction for fewer, cleaner shape paths. It was not selected as the first competitor because flat region labels alone struggle with broad photographic gradients, texture, and illumination.
- **Adaptive contour and Bézier fitting:** fit error-bounded cubic segments after region/topology extraction, with separate tolerances for silhouette-critical and low-contrast boundaries. Use only after deciding region ownership; curve fit does not resolve segmentation.
- **Optimized gradient meshes:** make mesh topology and color controls part of an optimization objective, ideally with continuity regularization. More expressive than the present per-cell linear gradient but greater implementation and solver complexity.
- **Surface appearance decomposition:** attempt to separate object/base color, diffuse shading, specular highlights, cast shadows, and alpha/transparency using a layered reflectance or intrinsic-image model. A single already-composited RGB image is under-constrained without priors or interaction; V04 therefore approximates final appearance and does not claim intrinsic-layer recovery.
- **Differentiable path optimization:** optimize an initial vector scene against pixel/perceptual/edge losses, regularized for path count, smoothness, topology, and editability. Pixel losses alone will tend to overfit source details unless complexity and semantic constraints are included.
