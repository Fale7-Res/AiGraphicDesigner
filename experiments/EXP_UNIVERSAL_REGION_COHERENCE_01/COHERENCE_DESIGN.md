# C: bounded within-partition coherence control

This is an independent derivative of the exact P input. It does not change selection, segmentation, region ownership, source coordinates or source predictions. `refine(items, originaltraces)` returns copied items and a complete decision audit. Each P chain must supply `trace_id`, `curves`, `closed`, `partition_ids`; source traces supply `trace_id` and `source_points_xy`. Both inherited numerical modules must be on the caller's import path.

One candidate is attempted for each of the first 32 longest accepted chains, with a 30-second cooperative deadline. Each original P source interval gets chord-length least-squares cubic fitting constrained to its original endpoints and the inherited one-sided endpoint tangent directions. Positive handle lengths are mandatory. A failed one-cubic fit is divided at balanced source arclength, recursively up to depth 10 and 64 cubics per original partition. No benchmark identity, evaluation reference or semantic hint enters the fitter. The 512-cubic original-trace budget cannot increase because a candidate must strictly reduce its chain's cubic count.

The bidirectional sampled numerical envelope stays at **0.6 px**, including the inherited 0.005 sampling plus 0.002 flattening allowances. Every final interval is rechecked against the original unsmoothed trace interval. P interval endpoints preserve source intentional-corner locations and the endpoint tangent constraints preserve their original one-sided directions. Candidate closure, nonzero area orientation, simple-chain status, mutual proper crossings/overlaps, contact incidence, duplicate geometry, nesting and severe new tangent jumps are checked against the exact P comparison. A failure rolls back the entire chain; originals and metadata are retained. Intersection and flattening tests are numerical, not certified continuous arithmetic.

No raw pixel-path/box fallback is generated. A rollback is recorded as a negative result, not a successful refined curve. Remaining chains beyond the 32-chain cap or after the deadline are explicitly unattempted. The deadline is cooperative: an ongoing numerical measurement and audit diagnostics can finish after it; the parent process-tree monitor supplies an external hard bound.

Why this method: P's tiny chord-derived segments can represent a smooth sampled arc with redundant internal handles. Endpoint-constrained least squares tests whether larger continuous spans fit under the unchanged source envelope. Increasing global RDP epsilon would confound simplification with a weakened approximation policy. Gaussian smoothing was not selected because it moves the evidence and can erase corners/width without an explicit original-trace constraint. Global spline refitting was not selected because it can move shared anchors and alter several variables together. This control intentionally cannot repair missing upstream evidence or P partition anchors that themselves encode staircases.

Before/after audit metrics keep cubic count, sampled short-span length fraction, integer-grid sample fraction, derivative tangent jumps, within-cubic turning, and sampled curvature separate. They are geometry proxies; no metric proves complete artwork, accurate visible area or professional curve quality. A positive cubic reduction is not geometric acceptance.

Seven generic tests passed before benchmark execution: circle reduction (16 to 8 cubics), jagged staircase preservation/rollback, intentional L-corner preservation, shared-junction endpoint preservation, opposite-orientation nested loops, explicit provenance rollback, and distinct curvature/short-span diagnostics. The circle is a numerical unit fixture, not a claim of real-image generalization. No benchmark was run by this module's implementation agent.

Reproduce tests from the session workspace with `work\agd-native\Scripts\python.exe work\universal_geometry\coherence\test_coherence.py`. The test wrapper adds existing repository modules and the isolated `work/geometry-deps` dependency location; no package installation or inference occurs.
