# Research data flow

`universal_run.selection_rank`: consumes frozen source trace records plus native RGB; returns source-only ranking/feature ledger. No evaluator dependencies. Does not bypass P >=6px limit.

`universal_run.run_universal_case`: reuses cached O/P for six sources; creates unchanged classical traces/O/P only for Burger/Logo/Camera; runs S/R/C independently; outputs loss ledgers, geometry and audits. Fine outputs remain owner-local.

`region_integration.integrate`: consumes original accepted cubic arrays, native dimensions/RGB; returns shared-reference atomic face graph and exhaustive unintegrated ledger. It does not infer missing endpoints/holes/semantics.

`coherence_refine.refine`: consumes exact P curves and source trace intervals; returns same-schema curves with conservative rollback/audit under unchanged0.6px gate. First32chain scope.

`evaluate_universal`: evaluator-only truth and guide access; selection/fitting/geometry metrics remain separate. `region_scope_metrics` separates actually integrated boundaries from all retained proposals. `graph_diagnostic` is post-run attribution, never construction input. `combined_control` runs only the frozen S+R gate and does not tune either method. `build_review` creates side-by-side native/4x/16x output views.

Historical fitter, partitioner, renderer, trace extractor, corrected SVG exporter and reference definitions are imported at frozen hashes, never overwritten. Exact shared endpoints and original cubics flow to serialization; flattening is only numerical measurement. Full appearance, semantics and production integration remain outside scope.
