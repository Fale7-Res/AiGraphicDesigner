## Deviations that constrain interpretation

1. Upstream512 inference exceeded the frozen sampled memory stop. One256 fallback was documented before completed predictions and then applied consistently. Native classical versus resized learned evidence is a feasible-laptop-system comparison, not equal-resolution neural architecture superiority.
2. Initial four construction runs sampled the Python launcher only. Their true peak RAM and768MiB enforcement are **NOT_ESTABLISHED**. Later holdouts use a process-tree monitor. Model inference uses tree monitoring. Sampling can miss peaks/brief stop-limit overshoot. Final report exposes these facts.
3. SVG display strokes are0.35px rather than protocol0.7px, consistently across arms. Centerline proximity metrics are separate from width-dependent render/coverage interpretation. Outputs were not retroactively changed.
4. Fitter acceptance uses numerical deviation, not a certified topology predicate. The simple-path field is diagnostic. No topology-safe production claim is justified.
5. Fixed length/trace/cubic budgets select different portions of each detector's evidence. Raw-all, selected and fitted stages must remain separate. Lower fitted recall alone cannot identify worse detection.
6. Anti-grid metrics are useful diagnostics, not proof of professional geometry. The length×width microgeometry proxy is not actual visible area. No rectangle/pixel-cell fallback was found, but lattice-derived traces and oscillations remain.
